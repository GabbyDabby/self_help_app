# 🎮 Self Help RPG

> **A gamified self-help and chore tracker designed like an RPG.**

Turn your everyday tasks, habits, and goals into an adventure. Complete tasks, earn points, customize your character, and face consequences when you leave tasks unfinished.

---

## ✨ Features

### 🧑‍🎨 Character Customization

Create your own character with customizable:

* 🎨 Skin Tone
* 🧍 Body Shape
* 😊 Face Style
* 👁️ Eye Color
* 👗 Clothing
* 💇 Hairstyles

---

### 🎯 Task & Goal Tracking

Stay on top of your daily responsibilities by turning them into RPG objectives.

* 📋 Track daily tasks
* ⭐ Earn points for completing tasks
* 🎁 Spend points on character customization
* 📈 Work toward personal goals
* ⚔️ Fight an enemy when a task is left incomplete

---

## 🗺️ Game Loop

```text
       ┌──────────────┐
       │  Create Your │
       │   Character  │
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │ Add Tasks &  │
       │    Goals     │
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │ Complete     │
       │    Tasks     │
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │ Earn Points  │
       │      ⭐      │
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │ Customize    │
       │  Character   │
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │   Missed a   │
       │     Task?    │
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │  ⚔️ Enemy    │
       │    Battle    │
       └──────────────┘
```

## 💡 Project Goal

The goal of **Self Help RPG** is to make everyday responsibilities feel more engaging by combining productivity tools with RPG mechanics.

Instead of simply checking off a chore, players can **complete objectives, earn rewards, customize their character, and progress through their own personal adventure.**
