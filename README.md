# Self Help RPG

An RPG styled gamified self help and chore tracker app 

---

##  Customization

- Skin Tone
- Body Shape
- Face Style
- Eye Color

---

## 🧭 Objective

Keep track of your daily tasks, habits, and goals.

Your goals:
- Track daily tasks
- Earn points for task completion
- Use points to buy clothes/hairstyles
- If task is left uncompleted you must fight an enemy
